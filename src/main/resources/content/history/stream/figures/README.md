# 历史源流 · 非帝人物

不上时间轴，只进入 Year Pack「本年人物」，并参与 `GET /api/history/stream/search`。

- 必填：`id,name,role,fromYear,toYear`
- `role`：`minister`（卿相）/ `general`（武将）/ `scholar`（学人）/ `poet`（文人）
- `fromYear`–`toYear`：活跃窗（任职、从军、著书），不是生卒全长
- 可选：`personalName`（字）、`aliases`（通行别称，如「卧龙」「东坡」）、`polityId`、`note`、`uncertain`、`relatedEventIds`
- 每朝收教材级条目，见 `notables.json`（当前约 90 人）
