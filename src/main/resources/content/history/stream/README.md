# 历史源流（模块 C）内容目录

与 `content/history/days/`（历史上的今天）**完全分离**，禁止互相引用。

**产品面**：微信小程序。本目录 + `/api/history/stream/*` 是真相源；`/history/stream.html` 仅 demo / 联调，不为 Web 流量入口（见 `docs/09_历史功能模块.md`）。

| 文件 | 说明 |
| --- | --- |
| `eras.yaml` | 顶部时代 Tab |
| `polities.yaml` | 政权泳道 + groups + metaMarkers |
| `events/` | 事件点（秦→1949 主线分文件） |
| `rulers/` | 帝/王人物条（主线 + 辽夏金蒙等并立） |
| `lineages/` | 夏商等谱系名（无公历纪年） |
| `reigns/` | 年号段（主线及辽夏金、五代、十六国/十国按年可查） |

### 内容覆盖（肉）

- **帝系**：西周（约年）、东周天子与春秋战国诸侯（齐晋楚秦燕赵魏韩吴越）、秦、新、两汉、三国、两晋、十六国及附列、南北朝、隋唐、五代、十国、两宋、辽夏金、蒙古/元、明清（含后金）；**谱系**：夏十七王、商三十王（无年）
- **事件**：教材级节点约 350+ 条；公元空档已补马援、隆中对、钟离、天宝、宁远、蓝玉、四库开馆、道光即位等；约两成事件挂有 `idioms` 出典
- **非帝人物**：`figures/notables.json` 约 90 人教材级活跃窗（先秦诸子、两汉名将名臣、三国至近代）；`/search` 匹配姓名 / 字 / `aliases`
- **可继续**：更密的事件年点、更多成语挂件；`/meta` contentVersion（见 docs/11）

- 设计：`docs/10_历史源流_中国朝代设计.md`
- 边界：`docs/09_历史功能模块.md`
- 截断：**1949**
