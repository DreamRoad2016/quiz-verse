# 10. 历史源流 · 中国朝代 / 政权设计

> **模块**：仅服务 [历史源流（C）](./09_历史功能模块.md)，与「历史上的今天」无关。  
> **时间截断**：政权条与时代 Tab 最晚到 **1949**（中华人民共和国成立）；1949 之后不画长条。  
> **口径**：中国大陆通行通史教材 + 《中国历史纪年表》常见说法；夏商等标 `uncertain`。  
> **校核**：DeepSeek 多轮（mainline / 乱世 / 并立 / 分段 audit），原始答卷在 `scripts/data/history_stream/research/`。

---

## 10.1 设计目标

1. 时间轴上能画出**中国史主线**，乱世能看懂「谁和谁同时在」。
2. 数据可渲染：`eras`（顶部 Tab）+ `groups`（乱世折叠组）+ `polities`（泳道条）+ `metaMarkers`（单点标记）。
3. **id 永不复用**（「夏」≠「胡夏」，「后凉」≠「后梁」，「南凉」≠「南朝梁」）。
4. 先壳后肉：本文件对应的 YAML 可直接喂 C0；`events` 仍可为空。

## 10.2 年份约定

| 规则 | 说明 |
| --- | --- |
| 纪年 | 公元年；**公元前为负整数**（前 221 年 = `-221`） |
| 闭区间 | `fromYear` / `toYear` 均为**包含**该公历年 |
| 截断 | `toYear` 最大关心到 1949；民国条 `1912–1949` |
| 终点标记 | `metaMarkers.prc_founding @ 1949`，不做成延伸至今的政权条 |
| 争议 | `uncertain: true` + `note` 写清采用口径与异说 |

### 先秦内容口径（已落地）

| 层 | 策略 |
| --- | --- |
| 夏 / 商 | 政权条 `uncertain`；世系进 `lineages/`，**不上时间轴** |
| 西周 | 王年表进 `rulers/`，一律 `uncertain` + `yearPrecision: approx`（共和可标更稳） |
| 春秋战国 | 事件进 `events/pre_qin.json`；主要诸侯为 `eastern_zhou_states` 平行泳道 |
| 年号 | 先秦**不建** `reigns` |

### 已拍板的争议口径

| 议题 | 采用 | 异说（写入 note） |
| --- | --- | --- |
| 秦亡 | `-207` | 亦有 `-206` |
| 曹魏 / 西晋交替 | 魏 `220–265`，晋 `265–316` | 亦有 266 |
| 孙吴起年 | `222`（称吴王） | 亦有 229 称帝 |
| 前凉起年 | `317` | 亦有自 301 张轨牧凉 |

## 10.3 分层模型（乱世友好）

### 三个字段一起用

```
tier   → 默认显隐（缩放/简化时先藏谁）
axis   → 南北/统一主轴（南北朝双轨）
groupId→ 乱世折叠与图例（十六国、十国…）
lane   → 同轴内上下错开，避免条带重叠
```

### `tier`（显隐优先级）

| 值 | 含义 | 默认是否显示 |
| --- | --- | --- |
| `spine` | 教材主线王朝 / 南朝或统一序列 | 始终 |
| `parallel` | 重要并立（三国另一方、北朝、辽夏金、后金等） | 始终 |
| `fragment` | 碎片政权（十六国、十国等） | **仅当可视年窗较窄或用户打开「显示割据」** |

> C0 壳阶段可暂时 **全部画出**，但数据必须带对 `tier`，以免日后无法简化。

### `axis`（主轴）

| 值 | 用途 |
| --- | --- |
| `unified` | 统一或单一主线时期（秦汉、隋唐、元明清、民国…） |
| `south` | 南方序列：东晋 → 宋齐梁陈 |
| `north` | 北方序列：北魏 → 东/西魏 → 齐/周 |
| `other` | 不占南北主轴的割据（十六国、十国、辽夏金等） |

南北朝同屏时：**南 `axis=south` + 北 `axis=north`**，不要把北魏塞进「打了折的统一 spine」。

### `groupId`（乱世组）

| groupId | 年代约 | 说明 |
| --- | --- | --- |
| `pre_qin` | ～前 221 | 夏商周（不确定年代） |
| `three_kingdoms` | 220–280 | 魏蜀吴 |
| `sixteen_kingdoms` | 304–439 | 传统十六国 + 附列 |
| `eastern_jin` | 317–420 | 可与十六国同屏 |
| `southern_dynasties` | 420–589 | 宋齐梁陈 |
| `northern_dynasties` | 386–581 | 北魏及分裂后 |
| `five_dynasties` | 907–960 | 梁唐晋汉周 |
| `ten_kingdoms` | 902–979 | 十国 |
| `song_parallels` | 916–1279 | 辽 / 西夏 / 金（与两宋并立） |
| `mongol_transition` | 1206–1271 | 大蒙古国 → 元 |
| `ming_qing_transition` | 1616–1644 | 后金与明末并立 |

### 推荐泳道（`lane`）示意

```
统一时期:     [lane0 spine]

三国:         [0 曹魏] [1 蜀汉] [2 孙吴]

东晋+十六国:  [0 东晋]
              [1..n 十六国 fragment，按 sort 堆叠；附列代/冉魏/西燕靠后]

南北朝:       [south/0 宋齐梁陈]
              [north/0 北魏 → 东魏/北齐]
              [north/1 西魏/北周]

五代十国:     [0 五代更替]
              [1..n 十国]

宋辽夏金:     [0 北宋/南宋]
              [1 辽 → 金]
              [2 西夏]

明末:         [0 明] [1 后金→清]
```

实现上可用 `axis` 分轨 + `lane` 轨内排序；不必一次做自动避让算法。

## 10.5 政权清单（落库字段）

文件：`content/history/stream/polities.yaml`

```yaml
# 每条 polity
id: cao_wei           # 全局唯一，英文蛇形
name: 曹魏
shortName: 魏         # 窄条显示
fromYear: 220
toYear: 265
tier: spine           # spine | parallel | fragment
axis: unified         # unified | south | north | other
groupId: three_kingdoms
lane: 0
capital: 洛阳
sort: 2200            # 建议 大致 fromYear*10 + 次序
uncertain: false
note: "…"
```

## 10.6 乱世专节

### 10.6.1 三国（220–280）

- `cao_wei` spine / `shu_han` parallel / `eastern_wu` parallel  
- 吴起年取 222；晋承魏 265。

### 10.6.2 五胡十六国 + 东晋（304–439）

- **南方主轴**：`eastern_jin`（317–420），`axis=south`, `tier=spine`
- **十六国**：`tier=fragment`, `axis=other`, `groupId=sixteen_kingdoms`
- **传统十六国**（16）：汉赵、成汉、前凉、后赵、前燕、前秦、后燕、后秦、西秦、后凉、南凉、北凉、南燕、西凉、胡夏、北燕
- **附列**（adjacent，默认可随 fragment 显示）：代、冉魏、西燕  
- **首期不列**：段齐、翟魏、桓楚 等更边缘政权（避免泳道爆炸）
- **北方收束标志**：北凉亡 / 北魏统一北方 **439**（事件上可作 marker，政权上北凉 `toYear=439`）

### 10.6.3 南北朝（386/420–589）

```
南: 刘宋 → 南齐 → 梁 → 陈          axis=south tier=spine
北: 北魏(386–534)
      ├ 东魏(534–550) → 北齐(550–577)   axis=north lane=0
      └ 西魏(535–556) → 北周(557–581)   axis=north lane=1
```

- 隋 `581–618`：`axis=unified`；**589 灭陈**是统一完成事件，不改变隋的 `fromYear`。

### 10.6.4 五代十国（902–979）

- 五代：`tier=spine`, `groupId=five_dynasties`, 同 lane 顺序更替  
- 十国：`tier=fragment`, `groupId=ten_kingdoms`  
- Tab `five_ten` 收到 **979**（北汉亡），避免十国被切掉。

### 10.6.5 宋辽夏金元

- 两宋 spine；辽→金、西夏为 `parallel` + `groupId=song_parallels`
- `mongol_empire` 1206–1271（`parallel`）→ `yuan` 1271–1368（`spine`）

### 10.6.6 明清与截断

- 明 1368–1644；后金 `hou_jin` 1616–1636；清 1636–1912  
- 民国 1912–**1949**；`prc_founding` @ 1949  
- **不列**南明、1949 后任何延伸

## 10.8 显隐策略（产品）

| 可视年窗宽度 | 建议 |
| --- | --- |
| > 800 年 | 只显示 `spine`（+ 必要 `parallel` 如辽金） |
| 200–800 年 | `spine` + `parallel` |
| < 200 年或点开「割据」 | 加上 `fragment` |

南北朝 Tab 内默认开启南北双轴；十六国在窗内且宽度 < 200 时自动展开 fragment。

## 10.9 质量与后续

- 改年号必须改 `note`，并尽量补一轮 audit 脚本。  
- 学术论战不进 UI；只保留「通行口径」。  
- 地图疆域、都城经纬度：**非本设计范围**（字段可预留 `capital` 文本）。  
- 与猜人物题包人物 id：**不绑定**。
