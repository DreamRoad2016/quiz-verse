# 水浒传题包设计

> 配合 [小说题包流水线操作手册](./小说题包流水线操作手册.md)。  
> packId：`shuihu_120`（120 回全传口径）。

## 1. 产品定位

- 公开站「小说」分类下的正式世界；百科 + 猜人物共用同一题包。
- 人物：**必收 + 可收全部进库**（耳熟配角如王婆、郓哥不可缺）。
- **必须有个人姓名**（或可唯一定人的稳定专称）；纯身份称谓不进库（酒家、知县、猎户、庄客、军士等）。
- 正文：本机 corpus，不进 Git。

### 收录细则

| 进库 | 不进库 |
| --- | --- |
| 武松、宋江、潘金莲、西门庆、王婆、郓哥、武大 | 酒家、店主人、知县、猎户、乡夫、上户、庄客、军士 |
| 有姓名且有行动/对话/情节 | 群体（两个猎户、众军汉）、无名「那汉子」 |

## 2. 比对列（schema）

| 列 | type | 说明 |
| --- | --- | --- |
| 姓名 | identity | 绰号进 `aliases` |
| 性别 | exact | 男 / 女 |
| 阵营 | set | 可多标签；招安后常用 梁山+宋室 |
| 星位 | exact | 天罡 / 地煞 / 非星 |
| 座次 | number | 仅 108；非 108 **不写该 attr**（显示 —） |
| 活动区域 | set | 成名/驻扎地，路过不算 |
| 重点剧情 | set | 枚举 key，每人 1–4 个为宜 |
| 核心关系 | set | 其他实体 id，约 3–8 条 |

百科另有顶层字段 `summary`：一句话简介，**≤50 字**，不参与比对。

### 2.1 阵营枚举（key）

| key | 含义 |
| --- | --- |
| liangshan | 梁山 / 水泊 |
| song_court | 宋室朝廷 |
| fangla | 方腊 |
| wangqing | 王庆 |
| tianhu | 田虎 |
| family | 梁山亲眷家属 |
| local_force | 地方势力（祝家庄、曾头市等） |
| civilian | 市井及其他 |

「是否 108」用星位+座次表达，**不要**再用单独「108将」阵营值。

### 2.2 活动区域（示例，以 schema 为准）

梁山泊、汴京、沧州、江州、清风寨、二龙山、桃花山、祝家庄、曾头市、高唐州、大名府、蓟州、登州、睦州、孟州、阳谷、郓城、柴进庄 等（控制在约 12–25 个）。

### 2.3 重点剧情（示例）

拳打镇关西、倒拔垂杨柳、误入白虎堂、风雪山神庙、火并王伦、智取生辰纲、景阳冈打虎、血溅鸳鸯楼、江州劫法场、三打祝家庄、英雄排座次、征方腊…（完整 key 列表在 `schema.yaml`）。

## 3. 实体形状

```json
{
  "id": "sh_wusong",
  "name": "武松",
  "aliases": ["武二郎", "行者武松"],
  "summary": "景阳冈打虎，为兄报仇，后上梁山，征方腊。",
  "attrs": {
    "gender": "男",
    "camps": ["liangshan", "song_court"],
    "star": "天罡",
    "seat": 14,
    "regions": ["阳谷", "孟州", "梁山泊"],
    "major_plots": ["jingyanggang_tiger", "yuanyanglou"],
    "connections": ["sh_songjiang", "sh_wuda", "sh_panjinlian"]
  }
}
```

非 108 示例：无 `seat` 键；`star` 为 `非星`。
